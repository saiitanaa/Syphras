## How can you contribute to the project?

### 1. Report bugs
- You can report issues by going to Issues and tagging the issue with “bugs”

### 2. Suggest improvements
- You can suggest new features by creating an issue tagged with “enhancement”

- You can also create pull requests to propose internal improvements directly in the code

**You’ll be credited for your code improvements!**

---------

**Keep the code easy to read and consistent with the default syntax**

**Use only English syntax without any other external languages**
